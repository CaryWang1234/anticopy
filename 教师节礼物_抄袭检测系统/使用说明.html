作业抄袭检测系统 · 使用小指南

一个不用装任何软件、双击就能用的小工具，帮您快速比对作业、找出雷同答案。
下面这份说明不用一次读完，用的时候随手翻对应的一段就行。

想看哪段点哪段 怎么打开 手机上用 三种模式 录入答案 看懂结果 常见问题

1怎么打开（30 秒）

1
把这个文件夹放到您常用的位置（比如桌面），里面的 作业抄袭检测系统.exe 就是程序本身。
2
双击它，会弹出一个黑色的小窗口（那是后台，别关它），稍等两三秒，浏览器会自动打开操作页面。
3
直接在浏览器里用就好。用完关掉黑色小窗口，程序就停了；或者关浏览器标签页也行。
第一次打开，Windows 可能会拦一下：弹出蓝色提示"已保护 Windows / 未知发布者"时，点 「更多信息」→「仍要运行」。这是所有"自己做的、没花钱签名"的小程序的正常现象，不是病毒。

2想在手机上用（边收作业边拍）

电脑开着程序时，黑色小窗口里会印着一行 手机访问 地址，长这样：

📱 手机访问: http://192.168.1.23:5000

  1. 确保手机和电脑连的是同一个 WiFi。
  2. 用手机浏览器（微信里也行）输入上面那串地址，就能在手机上打开同样的页面。
  3. 手机上点"拍照"按钮会直接调用后置摄像头，收一份拍一份，很方便。
小提醒：那串地址里的数字，每次联网可能会变一点。若手机打不开，回电脑窗口看最新的地址重新输入即可。

3三种检测模式，先用第一种就够

页面顶部有三个模式按钮。给您的建议很简单：

模式什么时候用需要联网？
📝 文本检测 ★推荐最常用。您把标准答案和学生的答案文字放进去，马上出结果。不需要，全程离线可用
🖼️ 图片检测拍题目图片、由系统去搜题平台找标准答案。需要联网，且依赖外部平台，不一定能取到答案
🔍 API 搜题输入题目文字，系统自动去搜题平台找答案。同上，取决于外部平台能否返回结果
说句实在话：后两个模式要连外部的搜题平台（作业帮、小猿等），这些平台不一定对外开放，取不到答案时会提示失败。"文本检测"是完全免费、离线、稳定可用的，日常比对作业用它就足够了，建议从这里上手。

4怎么录入标准答案和学生答案

标准答案

在文本模式最上面的框里，粘贴或打出这道题的标准答案。

学生答案 · 三个办法随您挑

  • 一份份填：点 生成卡片 决定要检测几份，每张卡片写学生姓名、把答案文字贴进文本框。
  • 一次粘贴全班：点 📋 批量输入，每行写一份，格式 姓名,答案内容（不想写姓名就直接一行一份答案，会自动编号）。适合从别处复制过来的整段文字。
  • 上传 txt 文件：点 📁 上传文件，选一个 UTF-8 编码的 .txt，同样按"姓名,答案"解析。

关于"📷 拍照"

每张卡片右边的 📷 拍照 按钮，是给这份作业附上原始照片留作凭证用的——一个学生可以拍多张（比如好几页），在展开的结果里能看到缩略图。

请留意（重要）：目前拍照只作附件存档，还不会自动把照片里的字认成文字来比对。真正参与相似度计算的，是文本框里的答案文字。所以：拍照留证 + 把答案文字填进文本框，两者配合使用。只放了照片、没填文字的学生，检测时会被跳过。

5看懂检测结果

点 🚀 开始检测 后，上方是全班概况（检测份数、平均相似度、高风险数、抄袭率），下面是一份份的明细。每份的综合相似度会归到四个档：

安全 <30%基本没抄，写法差别大。
较低 30–50%有借鉴，一般正常。
注意 50–80%雷同偏多，值得看一眼。
高风险 ≥80%高度相似，多半是照抄。

相似度是基于"精确匹配 / 语序相似 / 关键词重合"三方面综合算出来的，仅供参考——它给的是线索，最终判断还是您最准。

把结果保存下来

  • 点 📥 导出报告，会下载一份文本报告，能存档或打印。
  • 点 📋 历史 标签，能看到之前检测过的记录，随时回看。
  • 点 ⚙️ 设置 可调"严一点还是松一点"（阈值）和三方面各占多少（权重），默认值已经挺好用。

6常见问题

Q：双击后浏览器没自动打开？

手动打开浏览器，地址栏输入 http://127.0.0.1:5000 回车即可。

Q：黑色窗口一闪就没了 / 打不开？

多半是第一次被 Windows 拦了。回到 第 1 段，在拦截提示里点"更多信息 → 仍要运行"。个别杀毒软件也会拦，暂时放行或加白名单即可。

Q：我的作业数据存在哪？会不会丢？

都保存在这个 exe 旁边的文件夹里（上传的照片在 uploads，历史记录在 detection_history.json）。只要别删这个文件夹，记录就在。全程在您自己电脑上，不上传到任何地方。

Q：换台电脑还能用吗？

能。把这个 exe 拷过去双击就行，那台电脑不需要装 Python 或任何环境。

Q：手机打开页面但没反应？

先确认手机和电脑连的是同一个 WiFi，再核对地址末尾的数字（:5000）没漏。

不用记全部，第一次就试试 文本检测：贴一份标准答案、贴几份学生答案，点"开始检测"，一眼就懂了。
