01

四种模式

标准答案不是必须的

TEXT

文本比对

标准答案对全班。六维指标加权，短答案自动收缩，不会因为「不会」两个字一样就判成抄袭。

  • 连续雷同片段定位到字符
  • 逐份给出六项分数
PAIRWISE

学生互查

没有标准答案也能用。两两比对后，把互相高度相似的学生连成疑似团伙，直接告诉你该找谁。

  • 相似度矩阵，点格子看明细
  • 团伙按「最不像的一对」排序
PAPER

整卷多题

逐题比对，再按每题分值折算整卷。先看「几道题雷同、占多少分」，而不是被平均分稀释。

  • 缺答的题从分子分母同时剔除
  • 指出最可疑的那道题
AIGC

AIGC 风格线索

句长整齐度、套话密度、抽象大词、具体信息等六项可解释信号，圈出最可疑的句子。

  • 只给线索，不给结论
  • 每项信号都附一句人话解释
02

结果不是一句话

示意界面，示例文本为虚构

学生 A光合作用把光能转化成化学能储存在有机物中，是植物生长的基础。

学生 B我觉得这件事挺有意思的：光合作用把光能转化成化学能储存在有机物中，所以叶子能长大。

  • 雷同片段按原文下标回填，直接高亮在教师看到的文本上，不是另算一份摘要。
  • 只有达到最小长度的连续块才算证据；标点、空格、全半角差异不影响判定。
  • 每条结果同时保留原始分与校准后的分，教师能看出分数被动过手脚没有。
03

这个工具不做什么

比功能更需要说清楚

不给结论

输出的是线索强度和可核对的证据。要不要认定为抄袭、怎么处理，是教师的事，工具不替人下判断。

承认会误报

AI 文本检测对认真套用作文模板的学生存在系统性误判。AIGC 结果只能用来决定先找谁聊，不能当作定性依据。

不偷偷联网

所有比对在本机完成。需要外部接口的功能默认关闭，必须显式点击，且受每日预算上限约束。

04

跑起来

Windows / macOS / Linux 均可

  1. 装依赖

    需要 Python 3.10 以上，Flask + jieba，没有数据库。

  2. 启动

    默认自动打开浏览器；控制台会打印手机也能访问的局域网地址。

  3. 也可以打包成 exe

    仓库内附 PyInstaller 配置，断网、不装 Python 的教室电脑也能用。

# 1. 安装依赖
$ pip install -r requirements.txt

# 2. 启动 Web 界面
$ python main.py

# 3. 命令行 / 自测
$ python main.py demo
$ python selftest.py

设置保存在程序目录，重启不丢；检测历史与导出的报告也都在本地。

05

可选的大模型能力默认关闭

不配也能用全部本地功能

  • 生成参考答案：搜不到标准答案时，按题干生成一份供比对，教师确认后才填入。
  • AIGC 二次判别：只把最可疑的几句送去接口，姓名与长数字串先做替换。
  • 密钥不出本机：只存在本机 secrets.json，设置接口只返回脱敏后的形式。
  • 费用看得见：相同请求命中缓存不重复计费，当日花费达到预算即停止调用。
