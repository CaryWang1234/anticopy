01

四种模式

没有标准答案也能查

TEXT

文本比对

标准答案对全班。六项指标加权，短答案自动收缩，不会因为「不会」两个字一样就判成抄袭。

  • 连续雷同片段定位到字符
  • 逐份给出六项分数
PAIRWISE

学生互查

没有标准答案也能用。两两比对，把互相高度相似的学生归成一组，先找谁、从哪对看起，都列出来。

  • 相似度矩阵，点格子看明细
  • 分组按「最不像的一对」排序
PAPER

整卷多题

逐题比对，再按每题分值折算整卷。平均分容易把问题摊薄，这里先看有几道题雷同、占多少分。

  • 没答的题不计入汇总
  • 指出最可疑的那道题
AIGC

AIGC 风格线索

句长整齐度、套话密度、抽象词、具体信息，六项信号分开算，再圈出最可疑的句子。

  • 只给线索，不给结论
  • 每项信号都附一句人话解释

03

这个工具不做什么

先把这些说在前面

不给结论

输出的是线索强度和能逐条核对的证据。算不算抄袭、怎么处理，由教师决定，工具不替人下结论。

承认会误报

AI 文本检测容易冤枉认真套作文模板的学生。AIGC 结果只能用来决定先找谁聊，不能当作定性依据。

不偷偷联网

所有比对都在本机完成。需要外部接口的功能默认关闭，要用得自己点开，还有每日预算上限。

04

跑起来

Windows / macOS / Linux 均可

  1. 装依赖

    需要 Python 3.10 以上，Flask + jieba，没有数据库。

  2. 启动

    默认自动打开浏览器；控制台会打印手机也能访问的局域网地址。

  3. 也可以打包成 exe

    仓库里带了 PyInstaller 配置。教室电脑没装 Python、也断网，用 exe 照样跑。

# 1. 安装依赖
$ pip install -r requirements.txt

# 2. 启动 Web 界面
$ python main.py

# 3. 命令行 / 自测
$ python main.py demo
$ python selftest.py

设置存在程序目录，重启不丢；检测历史和导出的报告也都留在本地。

05

可选的大模型能力默认关闭

不配也能用全部本地功能

  • 生成参考答案：搜不到标准答案时，按题干生成一份供比对，教师确认后才填入。
  • AIGC 二次判别：只把最可疑的几句送去接口，姓名与长数字串先做替换。
  • 密钥不出本机：只写在本机的 secrets.json 里，界面上只显示打码后的样子。
  • 费用看得见：重复请求命中缓存就不再计费，当天花到预算上限就停止调用。
